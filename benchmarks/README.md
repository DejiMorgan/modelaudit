# Synthetic evaluation fixture — 60 examples

These 60 cases were constructed for **software validation and demonstration**. They are not observations from a real institution or a published benchmark, and do not support claims about real-model performance.

There are 20 examples for each reference label. The dataset supplies complete evidence sets for the supported and refuted examples. The 20 `NOT_ENOUGH_INFO` cases have no complete evidence sets; they are intentionally excluded from the citation-completeness denominator. This is a limitation of the fixture, not proof that citation completeness for those cases is zero.

To run: import `modelaudit_synthetic_60.json` in the Dataset screen, create an experiment with the mock adapter and run it. The mock adapter's performance is intentionally arbitrary, not a scientific baseline.
